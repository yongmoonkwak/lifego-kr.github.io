    서비스 개요

    「인생여정 동행서비스」는 이사·출산·결혼·상속 등 국민의 삶의 사건(생활이벤트)을 기준으로 여러 기관에 흩어진 행정·신청 업무를 하나의 패키지로 안내·실행하는 전자정부프레임워크 기반 공공서비스 플랫폼입니다.

    주요 기능

    • 생활이벤트 패키지 — 15개 인생여정별 단계별 할 일 및 서비스 안내
    • 서비스 카탈로그 — 164개 행정서비스를 구조화된 DB로 제공
    • 동행 대시보드 — 신청 진행 상황 통합 타임라인 조회
    • 법령 변경 알림 — 법령·지침 변경 시 영향 서비스 자동 탐지

    법령 준수 사항

    • 인공지능기본법 제16조 — AI 이용자 고지
    • 개인정보보호법 제37조의2 — 자동화 결정 설명·이의제기
    • 공공누리 출처 표시 의무화
    • 최소 개인정보 수집 원칙
    데이터 출처: 정부24 생활가이드, 국가법령정보센터, 법제처 생활법령정보, 각 소관기관 Open API
    프레임워크: 전자정부 표준프레임워크(eGovFrame) 기반 · Spring Boot · React 구현
    버전: v0.75 (2026.04.20 기준)
